# Release notes

The canonical release record is the [WolfMarkDown v1.0.3 GitHub Release](https://github.com/WolfMarkTools/WolfMarkDown/releases/tag/v1.0.3).

This release improves how meaningful numbering and source lists survive Markdown cleanup, adds safer citation repairs, and makes verification reports clearer. Routine dependency repairs preserve the agent's existing skill setup.

This repository does not maintain a second detailed release history. For current automated and historical validation evidence, see [Validation and evidence](./validation.md).
